# AuraClaw 新增文件清单


## 1. 总体结论

新版本实质改动集中在三件事：

1. **主线：价格洞察原子 Tool 默认改由 Java Agent Runtime 执行**  
   Skill 名称、11 个 ToolCapability、模型可见的输入/输出契约保持不变。Python 侧新增 AgentSession 入站绑定（claim / resolve）、共享 Workload Token、一次性 Tool Assertion，以及 Java DTO 到现有 snake_case 契约的适配。
2. **辅线：修复 MySQL 对 `UPDATE ... RETURNING` 的错误模拟**  
   解决 `claim_finalize` 一类“先 UPDATE 再按原 WHERE 回查”导致行找不到的问题；因此 `compose.hotfix-errors.yml` 变成空 overlay。
3. **现网联调补丁：页面对话直接调用 Java 原子 Tool，且带授权绑定后仍能被编排选中 Runtime**  
   模型不再先走 Python catalog（search / load / activate）；`required_capability.agent_auth` 只作赋值元数据，不参与 Runtime 能力匹配。这 4 个文件已从 `10.244.16.131` 现网源码同步进 `D:\PythonProject\AuraClaw-dev`。

## 2. 主线改动：Java 价格洞察原子 Tool 接入

### 2.1 业务目标

更新前的价格洞察 Tool 在 Python 进程内用 fixture JSON 或直连 MySQL DWD 计算。新版本把这条执行路径改成：

```text
页面/桥接层
  → Task API 入站（handoffCode 或 accessToken）
  → Java claim / resolve（Workload Token）
  → Session Event 只保存安全绑定（agentSessionId + conversationId）
  → RunnableItem.required_capability → Runtime MCP metadata
  → Action Hands 向 Java 申请一次性 Tool Assertion
  → 业务请求只带 X-CT-Tool-Assertion / X-CT-Invocation-Id / Content-Type
  → Java 原子 Tool 计算并返回
  → Python 适配器把 camelCase DTO 转回现有 snake_case Tool 契约
```

敏感证明（`handoffCode`、页面 `accessToken`、Workload Token、一次性 Assertion）不得进入事件、Snapshot、日志、响应或模型上下文。

授权证明只允许两种组合：

- **claim**：`agentSessionId + handoffCode`
- **resolve**：不含 `agentSessionId` 的 `conversationId + accessToken`

裸 `agentSessionId` 或混合证明会被拒绝。

### 2.2 配置开关

| 配置项 | 默认 | 作用 |
| --- | --- | --- |
| `AURACLAW_PRICE_INSIGHT_TOOL_BACKEND` | `java` | `java` 走 Java 原子 Tool；`python` 仅离线调试走进程内 fixture/MySQL |
| `AURACLAW_JAVA_AGENT_RUNTIME_BASE_URL` | 空 | Java Agent Runtime 地址 |
| `AURACLAW_JAVA_AGENT_RUNTIME_WORKLOAD_TOKEN` / `_FILE` | 空 | 至少 32 字符的共享 Workload Token |
| `AURACLAW_JAVA_PRICE_INSIGHT_USER_ID` | `100` | 转发给 Java Tool 的 user_id |
| `AURACLAW_JAVA_TOOL_ASSERTION_RETRY_COUNT` | `1` | Assertion 过期时最多重签并重试一次 |
| `AURACLAW_JAVA_TOOL_TIMEOUT_SECONDS` | `30` | Java HTTP 超时 |

生产 Compose 只把 Workload Token 挂给 `task-api`（绑定 AgentSession）和 `action-hands`（签发 Assertion），其它服务读不到该 Secret。
